# Prompt System

This directory stores reusable prompts for agents, RAG, rewriting, classification, and evaluation.

Suggested structure:
- prompts/system
- prompts/rag
- prompts/agents
- prompts/rewrite
- prompts/classify
- prompts/evaluation

Engineering rules:
- Avoid hardcoded prompts in business logic.
- Version prompts when possible.
- Keep prompts modular and reusable.
- Separate system prompts from workflow prompts.
