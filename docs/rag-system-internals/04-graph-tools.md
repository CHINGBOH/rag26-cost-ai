# 知识图谱与关联推理工具

## concept_search — 概念节点检索

concept_search 在 Neo4j 知识图谱中查找与关键词相关的概念节点及其周边关系。它不只返回节点本身，还返回节点的相邻关系（include_evidence=True 时）。例如搜索"企业管理费"，除返回该节点外，还会返回它的上位概念"间接费"、下位概念"管理人员工资""办公费"等关联信息。适合做概念扩展、发现相关知识范畴。参数：query（概念关键词），top_k（默认 6），include_evidence（是否包含关联证据，默认 True）。

## graph_search — 图结构全局检索

graph_search 在整个 Neo4j 图结构中做全局检索，返回与查询最相关的节点和关系集合。与 concept_search 不同，graph_search 更侧重于找到一组相关节点和它们之间的关系网络，适合探索式查询，例如"建设工程造价的费用构成有哪些"。参数：query（问题），top_k（默认 10）。

## topology_search — 拓扑路径检索

topology_search 从一个起始概念出发，沿图边向外扩展检索，找到 N 跳以内所有可达的相关概念。这对于"X 涉及哪些相关内容"类问题非常有效。max_depth 参数控制最大跳数（默认 2），top_k 控制返回节点数（默认 10）。深度越大，返回的概念越广但也越发散。适合全面了解某主题的关联知识体系。

## concept_neighbors — 概念近邻检索

concept_neighbors 查找指定概念的直接邻居节点，即与之直接相连的概念。hops 参数控制跳数（默认 1），top_k 控制返回数量（默认 15）。适合快速了解某个专业术语的"上下文"——它属于哪一类、包含哪些子项、与哪些概念并列。例如查"规费"的近邻，会返回"工程排污费"、"社会保险费"等组成部分。

## concept_path — 概念间路径检索

concept_path 查找两个给定概念之间在知识图谱中的最短路径，最大跳数可配置（默认 4）。适合回答"A 和 B 是什么关系"类问题。例如 from_concept="人工费" to_concept="建设工程费用"，系统会返回人工费→属于→直接费→属于→分部分项工程费→属于→建设工程费用的完整路径链。

## entity_cooccur — 实体共现分析

entity_cooccur 分析给定实体与哪些其他实体在文档中频繁共同出现。这有助于发现隐性关联——虽然在知识图谱中没有直接关系边，但经常出现在同一文档段落中，说明存在实际业务关联。参数：entity（实体名），top_k（默认 20）。适合发现文档中的隐性知识关联。

## upstream_downstream — 上下游关系检索

upstream_downstream 分析某个费用项目或流程节点的上游（前置条件、依赖项）和下游（后置影响、被依赖项）关系。direction 参数可以指定"upstream"（只查上游）、"downstream"（只查下游）或"both"（默认，双向）。适合解答"这个费用由什么构成"（上游）和"这个费用影响什么"（下游）类问题。
