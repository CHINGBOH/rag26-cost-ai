# 价格查询与趋势分析工具

## price_query — 价格精确查询

price_query 是建设工程造价信息价查询的专用工具，从 PostgreSQL 的 price_records 表中检索结构化价格数据。核心参数：material_name（材料名称，如"普通硅酸盐水泥"）、specification（规格型号，如"P.O42.5"）、year_month（年月，格式"2026-01"，不指定则取最新）、top_k（最多返回条数，默认 5）。返回内容包括含税价、不含税价、规格型号、信息来源月份、来源文档。系统会对 material_name 做模糊匹配扩展，"水泥"可以匹配到"普通硅酸盐水泥"等具体型号。

## price_query 使用注意事项

查询价格时有几点需要了解：数据范围仅限已上传并索引的信息价文档，系统不能查询未上传的价格数据；规格型号尽量提供精确型号（如 P.O42.5），模糊查询会返回多个型号结果供参考；年月如果省略，系统自动返回最新期数据；如果查不到，系统明确返回"无匹配记录"，不会猜测价格。价格数据来源是企业上传的深圳市建设工程材料信息价等官方文件，不是网络爬虫数据。

## price_trend — 价格趋势分析

price_trend 分析某种材料在一段时间内的价格变化趋势。参数：material_name（材料名称），start_month（起始月，如"2025-01"），end_month（截止月，默认最新）。返回按时间排列的价格序列数据，前端会自动将其渲染成折线趋势图，展示在"运行沙盘"面板中。适合回答"过去一年某材料价格走势如何"、"哪个月份价格最高"类问题。

## 价格数据更新机制

价格数据通过上传信息价 PDF 文件自动更新。上传新的月份信息价文档后，OCR 服务解析 PDF 中的表格，自动提取材料名称、规格型号、含税价、不含税价等字段，写入 price_records 表。旧记录按月份保留，不会被覆盖，因此可以做历史对比分析。同一材料、同一规格、同一月份的记录会做去重处理，避免重复上传导致数据混乱。

## 价格查询的局限性

系统价格查询有以下几个客观局限：第一，只能查询已上传文档中的价格，如果某种材料的信息价文档尚未上传，查询返回空结果；第二，信息价是政府发布的参考价格，与市场实际成交价可能有差异；第三，不同地区的信息价需要分别上传，系统不做跨地区价格换算；第四，特殊规格或小众材料可能在信息价文件中没有收录。遇到查询无结果时，建议检查文档管理页面确认相关月份的信息价文件是否已上传。
