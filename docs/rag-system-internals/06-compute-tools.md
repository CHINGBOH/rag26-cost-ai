# 计算工具与安全沙盒

## calculator — 数学表达式计算器

calculator 是最简单的计算工具，接受标准数学表达式并返回计算结果。支持基本运算（+、-、*、/、幂运算）和 Python math 模块函数（sqrt、round、ceil、floor、log 等）。示例：expression="500 * 0.08" 返回 40.0；expression="round(3.14159 * 100, 2)" 返回 314.16。执行环境完全隔离：无文件 IO、无网络访问、无 import 语句，执行超时限制 2 秒。适合造价计算中的单步数值运算，如"人工费 500 万乘以管理费费率 8%"。

## python_eval — Python 代码沙盒

python_eval 是功能更强大的计算工具，可以执行完整的 Python 代码片段。适合复杂多步骤计算、统计分析和数据处理。code 参数是要执行的 Python 代码，chunks_json 参数可以把检索到的结构化数据传给代码使用，让代码能访问知识库查到的实际数值。支持的安全库：numpy（数值计算）、math（数学函数）、statistics（统计分析）、json（数据解析）。禁止的危险模块：os、sys、subprocess、open（文件操作）、requests（网络访问）、importlib。代码执行在独立子进程中，资源限制（CPU/内存上限），超时自动终止。

## 计算过程在前端的展示

当 Agent 调用了计算工具后，计算过程会在前端"运行沙盘"面板实时展示，包括：完整的计算代码或表达式、每个中间步骤的数值、最终计算结果和单位说明。这样用户不仅能得到答案，还能看到计算过程，方便核对和复用。例如计算某工程综合费用时，系统会展示分步骤：先查到各费率 → 列出计算公式 → 逐步运算 → 汇总结果。

## 计算安全保障机制

系统对计算工具实施多层安全防护：代码运行在独立子进程，与主服务完全隔离，即使代码崩溃也不影响服务；通过 AST（抽象语法树）分析检测并拒绝危险操作；内存上限防止大循环耗尽资源；CPU 时间上限防止无限循环；所有异常都被完整捕获并返回友好错误信息，不会暴露服务器内部细节。

## 何时 Agent 会使用计算工具

Agent 根据问题类型自动决定是否调用计算工具。触发条件：问题中包含需要计算的数值操作（如"计算企业管理费"、"总费用是多少"）；需要汇总多项费用；需要做百分比换算；需要统计分析（如平均价格、价格涨幅百分比）。Agent 通常先用检索工具获取费率或价格数据，再调用 calculator 或 python_eval 执行实际计算，最后将检索来源和计算过程一起呈现给用户。
