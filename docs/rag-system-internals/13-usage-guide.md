# 使用指南与最佳实践

## 功能模块总览

系统主要有四个功能入口。企业知识库（主页）是日常查询的首选，极简界面，直接提问，系统自动完成所有检索和推理，隐藏了所有技术参数。RAG 问答（专业版）适合需要深入分析、需要看检索来源、需要调整检索参数的高级用户，三列布局展示对话、设置和推理过程。系统运维页面适合管理员查看系统健康状态和各服务运行情况。数据管道页面用于上传新文档、查看索引进度、管理知识库内容。

## 价格查询最佳实践

查询材料价格时，提供的信息越具体，结果越准确。推荐的提问格式：材料类别 + 具体规格型号 + 时间（年月）+ 可选地区。好的提问示例："2026 年 1 月深圳 P.O42.5 普通硅酸盐水泥含税信息价是多少？"不好的提问："水泥多少钱"（缺少规格和时间，系统会返回多个结果供选择，但准确性下降）。如果不知道规格型号，可以只给材料大类，系统会返回所有匹配规格及其价格供参考。

## 费率标准查询最佳实践

查询工程费率标准时，需要明确工程类别和计税方式。好的提问示例："建筑工程一般计税方式下企业管理费费率是多少？"、"深圳房屋建筑工程分包工程中，规费包含哪些项目，费率分别是多少？"不好的提问："管理费怎么算"（缺少工程类别和计税方式，不同类别的费率差异较大）。系统会自动识别计税方式（一般计税/简易计税）和工程类别（建筑/安装/装饰/市政等）并查找对应费率。

## 计算问题最佳实践

需要计算时，给出已知数据和计算目标。好的提问示例："某工程分部分项工程费 1000 万元，措施费 100 万元，按一般计税方式，企业管理费和规费分别是多少，综合造价是多少？"系统会：先检索对应费率标准 → 理解计算结构 → 调用计算工具执行 → 展示完整计算步骤和结果。计算结果会在"运行沙盘"面板展示完整推导过程，方便核对。

## 提问的三要素框架

好的问题通常包含三个要素。第一，对象：问的是什么（材料名称、费用项目、规范条款）。第二，限定条件：什么规格、什么时间、什么工程类别、什么计税方式。第三，目标：需要什么（查价格、查费率、做计算、找条文、解释含义）。三要素越完整，回答越准确。如果一时记不住，也没关系，系统会尽力理解模糊问题，只是结果精度会低一些，可能需要追问补充信息。

## 系统能做什么与不能做什么

系统能做的事：查询已上传文档中的任何信息（价格、费率、条文、规范）；做数值计算（造价汇总、费率换算、统计分析）；解释专业术语（基于文档内容）；分析价格趋势（基于历史信息价）；找概念之间的关系（基于知识图谱）。系统不能做的事：联网查询实时市场价格；修改数据库中的记录；预测未来价格（仅供参考）；回答知识库中完全没有的内容；处理非文字类请求（如生成图片、编写代码）。

## 遇到"信息不足"如何处理

如果系统回答"当前知识库中的信息不足以回答此问题"，可以按以下步骤排查。第一步，检查是否提问太模糊，尝试用更具体的术语重新提问。第二步，检查"数据管道"页面，确认相关文档是否已上传，状态是否显示"已索引"。第三步，如果文档已上传但仍找不到，可能是 OCR 识别质量问题（扫描件质量差会影响文字识别准确性）。第四步，如果确实没有相关文档，需要先上传。重新上传或新上传文档后，等待索引完成（通常 1-5 分钟）再重新提问。
