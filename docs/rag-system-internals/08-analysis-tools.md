# 高级分析与智能辅助工具

## stats_overview — 系统数据统计概览

stats_overview 返回整个知识库的统计摘要，包括：总文档数、总文本块数、各数据库状态、近期查询成功率、最常被检索的主题等。这是 Agent 了解"系统里有什么"的全局视图工具，无需参数直接调用。适合回答"系统里有多少资料"、"覆盖了哪些主题"类管理性问题。

## expand_question — 问题扩展与改写

expand_question 使用 LLM 将用户的原始问题扩展成多个角度的查询变体，提高检索召回率。例如"水泥价格"会被扩展为["普通硅酸盐水泥信息价 P.O42.5 含税价格"、"水泥材料价格 深圳 2026"、"硅酸盐水泥市场价"]等多个变体。参数：question（原始问题），n（生成变体数量，默认 5）。Agent 可以用这些变体分别检索，然后合并结果，显著提高复杂问题的检索覆盖率。

## suggest_followup — 智能追问建议

suggest_followup 根据用户的问题和系统的回答，智能生成 N 个相关的后续问题建议，引导用户深入探索。参数：question（原始问题），answer（当前答案），n（建议数量，默认 3）。这个工具生成的追问建议会显示在前端对话界面的底部，帮助用户发现他们可能没想到但相关的查询方向。

## find_knowledge_gaps — 知识盲点检测

find_knowledge_gaps 分析当前知识库对于给定问题的覆盖程度，找出哪些方面信息不足或没有覆盖。参数：question（问题），threshold（置信度阈值，默认 0.55）。返回：哪些子问题有良好覆盖、哪些子问题信息不足、建议上传哪些类型的文档来填补空白。这是知识库管理的重要工具，帮助管理员发现需要补充的文档类型。

## forecast_series — 时间序列预测

forecast_series 对价格或其他时间序列数据做趋势预测，基于历史数据预估未来走势。适合回答"根据历史趋势，下个季度水泥价格预计如何"类预测性问题。使用简单的时间序列模型（线性趋势 + 季节性调整），返回预测区间而非单点预测，体现不确定性。重要提示：预测结果仅供参考，不作为决策依据，系统会在结果中明确注明。

## outlier_detect、correlate、cluster_records — 统计分析工具

这三个工具提供高级统计分析能力。outlier_detect 用 IQR（四分位距）或 Z-score 方法检测数据表中某列的异常值，适合发现价格异常波动。correlate 计算两个数据列之间的相关系数（Pearson 或 Spearman），分析变量间关联程度，如分析不同材料价格的联动关系。cluster_records 用 K-means 聚类算法对数据记录分组，发现数据中的自然分类，如对价格数据做高/中/低区间聚类分析。

## 智能工具组合模式

Agent 在处理复杂问题时通常不只调用一个工具，而是组合多个工具。典型组合模式：价格趋势分析 = price_trend（获取数据）→ forecast_series（预测）→ python_eval（生成报告）；综合费用计算 = hybrid_search（查费率标准）→ price_query（查材料价格）→ calculator（计算汇总）；知识探索 = expand_question（改写问题）→ hybrid_search（检索）→ concept_neighbors（扩展概念）→ suggest_followup（生成追问）。
